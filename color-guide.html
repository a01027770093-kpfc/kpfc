Usage Guide

컬러 사용 가이드

헤더 / 네비게이션

배경: Primary Gradient, 텍스트: White, CTA: Accent (#4338CA)

CTA 버튼 / 강조

배경: Accent (#4338CA), hover 시 Accent Dark (#3730A3)

히어로 섹션

배경: Hero Gradient (#1D00AD → #150080), CTA: Accent

서브 섹션 / 카드

배경: Secondary Pale (#E8F0F8), 아이콘: Secondary (#1E3A5F)

푸터

배경: Gray 900 (#0F172A), 텍스트: Gray 400 (#94A3B8)

링크 / 인터랙티브

Primary (#1D00AD), hover 시 Primary Dark (#150080)

CSS Variables

복사하여 사용할 수 있는 CSS 변수

:root {
  /* Primary Colors - 딥 네이비 퍼플 (관공서 스타일) */
  --primary: #1D00AD;
  --primary-light: #2E1AE0;
  --primary-dark: #150080;
  --primary-pale: #E8E5F8;

  /* Accent Colors - 브라이트 인디고 (CTA, 강조) */
  --accent: #4338CA;
  --accent-light: #6366F1;
  --accent-dark: #3730A3;
  --accent-pale: #EEF2FF;

  /* Secondary Colors - 네이비 블루 (보조) */
  --secondary: #1E3A5F;
  --secondary-light: #2D5A87;
  --secondary-dark: #0F1D30;
  --secondary-pale: #E8F0F8;

  /* Status Colors */
  --success: #059669;
  --warning: #D97706;
  --error: #DC2626;
  --info: #4338CA;

  /* Neutral Colors - Slate */
  --neutral-50: #F8FAFC;
  --neutral-100: #F1F5F9;
  --neutral-200: #E2E8F0;
  --neutral-300: #CBD5E1;
  --neutral-400: #94A3B8;
  --neutral-500: #64748B;
  --neutral-600: #475569;
  --neutral-700: #334155;
  --neutral-800: #1E293B;
  --neutral-900: #0F172A;

  /* Gradients */
  --gradient-primary: linear-gradient(135deg, #1D00AD 0%, #2E1AE0 100%);
  --gradient-hero: linear-gradient(135deg, #1D00AD 0%, #150080 100%);
  --gradient-accent: linear-gradient(135deg, #4338CA 0%, #6366F1 100%);
  --gradient-secondary: linear-gradient(135deg, #1E3A5F 0%, #2D5A87 100%);
}
